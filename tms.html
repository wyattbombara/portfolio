tms site

A modified web proxy and game hub — built around the idea of keeping useful tools in one place.

Overview

tms brings web browsing, games, and tools together in a single site. The project combines a Node.js backend with Bare Server for the proxy infrastructure.

A gateway for the web.

The work spans both the interface and the infrastructure behind it: modifying the proxy site, bringing the game hub together, and keeping the service available. The self-hosted AI assistant is also accessible through tms.
